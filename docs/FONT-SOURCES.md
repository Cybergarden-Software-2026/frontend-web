# Шрифты МТС

Основной интерфейс использует MTS Text Regular/Medium/Bold; логотип — MTS Compact; крупные фирменные заголовки и декоративные клавиши — MTS Wide. Номера, таймеры и поля ввода также используют шрифты МТС.

Источник текущих файлов — предоставленный пользователем архив `mts_shrift.7z`, каталог `ШРИФТ/Web`. В интерфейсе используются WOFF2, объявленные в `src/fonts.css`. Для встраивания кириллицы в PDF добавлены MTS Text Regular/Bold в `public/fonts/report/` в формате TTF из того же архива. Они загружаются только при скачивании PDF; внешние запросы к сервисам шрифтов не требуются. Excel указывает семейство MTS Text; его отображение зависит от установленных на компьютере шрифтов.

В `public/fonts/` находятся семейства MTSText, MTSCompact и MTSWide с начертаниями Regular (400), Medium (500), Bold (700). Фирменные ресурсы принадлежат правообладателям МТС.
